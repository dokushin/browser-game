# browser-game

ブラウザで動くオリジナルゲームを、Claude Code のクラウド環境で作る練習用リポジトリ。

## 遊び方

`index.html` をブラウザで開く。

## ゲーム：ボールの気持ち 🏐

あなたはバレーボール。痛いのはイヤだけど、ラリーはずっと続けたい。
選手にさわられるたびに HP が減るので、こっそり軌道をずらして、やさしい人にさわってもらおう。

### 操作

| 操作 | スマホ | パソコン |
|---|---|---|
| ボールをずらす | 画面をなぞる | 矢印キー / WASD |
| ゆっくり落ちる | 「ふわっ」を押し続ける | Z |
| はやく落ちる | 「ストン」を押し続ける | X |

### ルール

- スコアは「ボールがさわられた回数」
- バレーのルールどおり、1チーム3回（レシーブ → トス → スパイク）で相手コートへ返す
- 強くさわる人ほど HP が大きく減り、やさしい人にふわっと上げてもらうと回復する
- ずらしたり落ちる速さを変えたりすると「審判の怪しみ度」がたまる。審判がよそ見している間はたまりにくい
- 30秒ごとに試合のレベルが上がる（練習試合 → 地区大会 → 県大会 → 全国大会 → 全国大会 決勝）
- ゲームオーバー：床に落ちる / HP が 0 / 審判にバレる / 4回さわる反則（フォアヒット）
- 自己ベストはブラウザに保存される

### 登場人物

| 顔 | 名前 | 特徴 |
|---|---|---|
| 😤 | 本気スパイクの先輩 | どのプレーも痛い。スパイクは特に痛い |
| 😇 | やさしいリベロ | さわられると回復する。スパイクは打たない |
| 🤗 | 話しかけてくる後輩 | ふつうの強さ。毎回ボールに話しかけてくる |
| 😎 | サーブだけ強い人 | サーブだけ痛い。それ以外はふつう |
| 😠 | 顔だけ怖い人 | 見た目はこわいけど、じつはやさしい（ゲーム中は説明しない） |
| 🙂 | ふつうの部員 | ふつう |

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の部品（HUD・ボタン・タイトル画面など） |
| `style.css` | 見た目 |
| `js/config.js` | 設定値（ダメージ・レベル・セリフなど）。数字を変えると難しさを調整できる |
| `js/sound.js` | 効果音（Web Audio API でその場で音を作る） |
| `js/input.js` | なぞる操作・ボタン・キーボードの受け取り |
| `js/game.js` | ゲームのルールと動きの計算 |
| `js/draw.js` | canvas への描画 |
| `js/main.js` | 全体をつなぐ（ゲームループ・画面の切りかえ） |
